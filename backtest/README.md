# 回测输出字段说明

> 更新时间：2026-08-06

---

## 一、CSV 列说明

回测结果保存在 `backtest/output/{时间戳}/{指数}_{名称}/{数据源}_top20.csv`，每行代表一组参数的回测结果。

### 1.1 基本标识

| 列名 | 含义 | 示例 |
|------|------|:---:|
| `window_years` | 滑动窗口年数，用过去 N 年的数据计算 PE/PB 百分位 | 3 / 5 / 8 / 10 |

### 1.2 绩效指标

| 列名 | 含义 | 解读 |
|------|------|------|
| `final_return` | 最终回报率 = (终值 − 投入) / 投入 | +48% = 赚 48% |
| `cagr` | 年化复合增长率（Compound Annual Growth Rate） | 5% = 每年平均涨 5% |
| `max_drawdown` | 最大回撤，从净值最高点到最低点的最大跌幅 | 32% = 最惨时亏了 32% |
| `sharpe` | 夏普比率，风险调整后收益 | >1 = 不错，<0.5 = 差 |
| `calmar` | 卡玛比率 = CAGR / 回撤 | 越高越好 |

### 1.3 资金流水

| 列名 | 含义 |
|------|------|
| `total_invested` | 累计投入总金额（元） |
| `final_value` | 最终市值（剩余份额 × 最终指数价格） |
| `trades` | 总交易次数（买入 + 卖出） |
| `buys` | 买入次数 |

---

## 二、策略参数

策略：每周定投一次，买入金额基准 1,500 元，根据 PE/PB/FED 三因子动态调整倍数。卖出每月最多一次。

### 2.1 买入阈值（4 个）

PE 百分位越低，买入倍数越高。约束：`floor < low < mid < high`，步进 5%。

| 列名 | 含义 | 对应行为 |
|------|------|------|
| `pe_buy_floor` | PE 百分位 < 此值 | **3×** 买入（极度低估，1500 → 4500） |
| `pe_buy_low` | PE 百分位 < 此值 | **2×** 买入（低估，1500 → 3000） |
| `pe_buy_mid` | PE 百分位 < 此值 | **1×** 买入（正常，1500 → 1500） |
| `pe_buy_high` | PE 百分位 < 此值 | **0.5×** 买入（偏贵，1500 → 750） |
| — | PE 百分位 ≥ high | **不买** |

### 2.2 卖出阈值（3 个）

PE 百分位越高，卖出越积极。约束：`warn < heavy < extreme`，步进 5%。

| 列名 | 含义 | 对应行为 |
|------|------|------|
| `pe_sell_warn` | PE 百分位 ≥ 此值 | **停止买入** + 预警 |
| `pe_sell_heavy` | PE 百分位 ≥ 此值 | **每月梯度减仓**（每次卖 5%~25% 持仓） |
| `pe_sell_extreme` | PE 百分位 ≥ 此值 | 进入**回撤清仓模式**（价格回调 3%~5% 后卖 25%~50%） |

### 2.3 否决/确认（3 个）

| 列名 | 含义 | 对应行为 |
|------|------|------|
| `fed_buy_threshold` | FED < 滚动均值 + N × 滚动标准差 | **禁止买入**（股债性价比不支持） |
| `pb_veto_threshold` | PB 百分位 ≥ 此值 | **取消所有买入**（PB 说估值偏贵） |
| `pb_confirm_threshold` | PB 百分位 ≥ 此值 | **确认卖出信号有效**（PE + PB 双因子共振） |

### 2.4 回撤清仓（2 个）

仅在 PE ≥ extreme 时生效。

| 列名 | 含义 |
|------|------|
| `drawdown_standard` | 标准回撤清仓阈值（当前版本暂未启用） |
| `drawdown_tight` | 极端泡沫时回撤清仓阈值，价格从高点回撤 ≥ 此值即卖出 25%~50% |
