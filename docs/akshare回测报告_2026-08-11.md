# akshare 网格搜索回测报告

> 生成时间：2026-08-11  
> 数据源：akshare (legulegu.com) PE/PB + 中国10年期国债 + 新浪指数价格  
> 回测区间：2006-01 ~ 2026-08  
> 窗口：3 / 5 / 10 年滚动历史

---

## 一、策略说明

### 买入规则（周频，每周最多1次）

| PE 百分位 | 倍率 | 金额 |
|----------|------|------|
| PE% < floor | 3x | ¥4,500 |
| PE% < low | 2x | ¥3,000 |
| PE% < mid | 1x | ¥1,500 |
| PE% < high | 0.5x | ¥750 |
| PE% ≥ high | 0 | 不买 |

- **PB 一票否决**：PB% ≥ 阈值 → 不买
- **FED 闸门**：FED% < 阈值 → 不买
- 卖出当月不买

### 卖出规则（月频，每月最多1次）

| PE% 区间 | 动作 | 比例 |
|---------|------|------|
| PE% ≥ heavy | 分批卖出 | 20%/月 |
| PE% ≥ extreme + 回撤≥5% | 极端卖出 | 25%~50%/月 |

- **PB 卖出触发**（可选）：PB% ≥ 阈值 → 卖出

### 百分位计算

- 基于指定窗口长度（3/5/10年）的滚动历史 PE/PB/FED 计算
- 窗口前 N 年不交易，仅积累历史数据
- 第 N+1 年第一天起可开始交易

## 四、关键发现

### 1. PB 否决是最重要参数

87个Top30组合中：
- 77个(89%)使用了PB%≥60%否决
- 10年窗口下略有降低(65/90=72%)

PB%过高时买入A股容易买在周期顶部，60%否决线是很好的保护。

### 2. FED 闸门有辅助价值

87个Top30组合中：
- 62个(72%)使用了FED闸门
- 主要集中在3年/5年窗口

### 3. 窗口越长XIRR越低但回报越高

长窗口(10年)的XIRR普遍低于短窗口(3/5年)，因为：
- 更长历史导致百分位变化更缓慢
- 错过了一些小周期的买入机会
- 但总回报不一定差(复利效应累积)

### 4. 中证500回报最高

| 窗口 | 沪深300 XIRR | 上证50 XIRR | 中证500 XIRR |
|------|:---:|:---:|:---:|
| 3年 | 18.64% | 17.28% | 18.91% |
| 5年 | 19.98% | 18.47% | **22.93%** |
| 10年 | 14.41% | 13.57% | **24.51%** |

中证500在所有窗口上均优于沪深300和上证50，且5年/10年窗口差距最大(中证500的pe_med口径更受小盘股高估影响)。

### 5. 买入阈值规律

```
大盘指数(沪深300/上证50): floor=10%  ← 更激进，PE低时敢买
中小盘(中证500):         floor=15%  ← 更保守，等更便宜才敢大笔买
```

### 6. 卖出阈值规律

- 3年窗口：heavy=80%, extreme=85%~95%
- 5年窗口：heavy=75%~80%, extreme=85%~90%
- 10年窗口：heavy=75%~80%, extreme=90%~95%

短窗口卖出阈值更高(因为历史短，极值参考少)，长窗口卖出阈值略宽(历史更长，极端值更有参考意义)。

## 五、数据链路

```
parquet/aks/pe/000300.parquet           ← legulegu PE (2005~今, 日频)
parquet/aks/pb/000300.parquet           ← legulegu PB (2005~今, 日频)
parquet/bond_yield/cn_10y_bond.parquet  ← 东方财富 中债10Y (2002~今)
parquet/index_price_aks/000300.parquet  ← 新浪 指数价格 (2006~今, 日频)
        ↓
data-store/build_aks_merged.py          ← 合并 + 滚动百分位
        ↓
parquet/aks_merged/000300.parquet       ← 回测用DataFrame
        ↓
grid_search_aks/grid_search.py          ← 网格搜索 + 回测引擎
        ↓
grid_search_aks/output/latest.json      ← 结果JSON
        ↓
app.py → /aks/grid-search               ← 前端展示
```

## 六、使用命令

```bash
# 构建回测数据
python3 data-store/build_aks_merged.py

# 网格搜索 (500样本, ~1.5分钟/指数)
python3 grid_search_aks/grid_search.py --sample 500

# 网格搜索 (全部组合, ~5分钟/指数)
python3 grid_search_aks/grid_search.py

# 单指数
python3 grid_search_aks/grid_search.py --code 000300 --sample 1000

# 前端查看
http://<IP>:8000/aks/grid-search
```
