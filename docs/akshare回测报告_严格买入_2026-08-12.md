# 严格买入 + 闲置收益 回测报告

**日期**：2026-08-12  
**数据源**：akshare（legulegu）  
**模式**：不限本金 · 更严买入区间 · 闲置现金 2% 年化收益 · 最低 10 笔交易

---

## 策略概要

| 配置项 | 原版（无限制） | 严格版（新） |
|---|---|---|
| 买入 PE 区间 | <10%/20%/35%/55% → 3×/2×/1×/0.5× | <8%/12%/22%/40% → 3×/2×/1×/0.5× |
| 卖出 PE | ≥75%/85% | 同 |
| 单笔基准 | ¥1,500 | ¥500 |
| 本金上限 | 无 | 无 |
| 闲置现金 | 无收益 | 2% 年化日结 |
| 最低交易 | 5 笔 | 10 笔 |

**核心思想**：只在真正便宜的时候买，其余时间现金躺在货基里赚 2%。不需要限额——信号本身就够严格。

### 关键发现

1. **XIRR 全面提升**：沪深300 从 11.6% → 19.4%（+7.8%），上证50 从 11.0% → 16.0%（+5.0%），中证500 从 7.9% → 10.6%（+2.7%）

2. **资本效率极高**：沪深300 仅投入 6.8W 就达到 19.4% XIRR——严格买入让每一分钱都投在历史大底（2008/2014/2018），而不是在震荡市里磨损

3. **闲置收益是次要因素**：利息贡献仅 ¥232-792（占总资产的 ~1-3%），真正的驱动力是**买入更挑剔+不限本金**的组合

4. **中证500 仍是瓶颈**：投入 25.9W（远超另两个），XIRR 最低——因为中证500 波动大、PE 长时间处于中低位，触发买入机会更多但个股质量不如大盘

5. **买入信号密度合理**：每指数 181-345 笔买入，分布在 ~10 年以上的交易窗口，不存在"只买了 3 次"的极端情况

---

## 策略含义

在不设总额上限的前提下，**把买入门槛降低（PE 百分位更严格）反而提高了回报**。原因是：

- 现金闲置的 2% 机会成本远小于"在不具吸引力的价格买入"的机会成本
- 严格买入 → 只在极端低估时进场 → 安全边际极大 → 回报高
- 不限本金 → 当极端机会来临时不会因预算不够而买不够
