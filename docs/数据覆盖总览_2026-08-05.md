## 一、项目结构

```
/mnt/data/zmp/
├── app.py                              # FastAPI 服务 (localhost:8000)
├── data-store/
│   ├── download_danjuan_pe.py          # 采集：蛋卷 PE（等权，周频）
│   ├── download_danjuan_pb.py          # 采集：蛋卷 PB（等权，周频）
│   ├── download_index_pe.py            # 采集：中证 PE（整体法，日频）
│   ├── download_bond_yield.py          # 采集：10年期国债收益率
│   ├── import_wind_data.py             # 导入：Wind PE 邮件附件 → wind_source/
│   ├── align_wind_data.py              # 对齐：Wind + 现有 → aligned_source/
│   ├── merge_indicators.py             # 合并：PE+PB+国债 → FED+百分位
│   └── parquet/
│       ├── index_pe/     (20文件)      # 原始 PE 采集输出
│       ├── index_pb/     (13文件)      # 原始 PB 采集输出
│       ├── bond_yield/   (1文件)       # 国债收益率
│       ├── wind_source/  (14文件)      # Wind 原始 PE（独立，不混入）
│       ├── aligned_source/(14文件)     # 对齐后 PE（Wind早期+现有近期）
│       └── merged/       (20文件)      # 合并输出（前端消费）
├── templates/
│   ├── index.html                      # 大盘总览（卡片网格）
│   └── detail.html                     # 指数详情（ECharts 图表）
├── docs/
│   ├── 蛋卷PE数据源验证报告_2026-08-05.md
│   └── 数据覆盖总览_2026-08-05.md
└── requirements.txt
```

## 二、快速开始

### 2.1 安装依赖

```bash
cd /mnt/data/zmp
pip3 install --user -i https://pypi.tuna.tsinghua.edu.cn/simple \
    pandas requests pyarrow xlrd fastapi uvicorn
```

### 2.2 下载数据（首次）

```bash
python3 data-store/download_danjuan_pe.py       # 蛋卷 PE
python3 data-store/download_danjuan_pb.py       # 蛋卷 PB
python3 data-store/download_index_pe.py         # 中证 PE
python3 data-store/download_bond_yield.py       # 10Y国债收益率
python3 data-store/merge_indicators.py          # 合并 → merged/
```

### 2.3 启动服务

```bash
cd /mnt/data/zmp
setsid python3 -u app.py &>/tmp/pedca.log & disown
```

服务运行在 `http://<服务器IP>:8000`，进程已脱离终端，关闭SSH不影响。

### 2.4 验证

```bash
curl http://localhost:8000/api/indices | python3 -m json.tool | head -20
```

## 三、日常更新流程

数据不会自动更新，需要手动跑脚本后刷新页面。

```
更新数据:
  python3 data-store/download_danjuan_pe.py
  python3 data-store/download_danjuan_pb.py
  python3 data-store/download_index_pe.py
  python3 data-store/download_bond_yield.py
  python3 data-store/merge_indicators.py

前端生效:
  打开 http://<IP>:8000 → 按 F5 刷新
```

**需要重启服务吗？** 不需要。FastAPI 每次请求实时读 parquet 文件，文件更新后刷新页面即可看到新数据。

**更新频率建议：**
| 数据源 | 更新频率 | 原因 |
|--------|---------|------|
| 蛋卷 PE/PB | 每周一次 | 周频数据，工作日每天更新但每周只多一个采样点 |
| 中证 PE | 每天收盘后 | 日频数据，每个交易日有更新 |
| 10Y 国债 | 每天 | 每天有报价 |

## 四、数据流水线

```
┌─────────────────────────────────────────────────────────┐
│                   数据采集阶段                            │
│                                                         │
│  download_danjuan_pe.py  ──→  index_pe/{code}.parquet   │
│  download_danjuan_pb.py  ──→  index_pb/{code}.parquet   │
│  download_index_pe.py    ──→  index_pe/{code}.parquet   │
│  download_bond_yield.py  ──→  bond_yield/cn_10y_bond    │
│                                                         │
├─────────────────────────────────────────────────────────┤
│                   合并计算阶段                            │
│                                                         │
│  merge_indicators.py     ──→  merged/{code}.parquet     │
│    · LEFT JOIN PE + PB + 国债 on date                   │
│    · PB 和国债收益率前向填充（周频→日频对齐）              │
│    · FED = (1/PE)*100 - 10Y_bond_yield                  │
│    · PE百分位 = rank(pe) / total × 100                   │
│                                                         │
├─────────────────────────────────────────────────────────┤
│                   可视化服务                              │
│                                                         │
│  app.py (FastAPI :8000)                                 │
│    · 每次请求实时读 merged/ parquet                       │
│    · 不设缓存，文件更新后刷新页面即可生效                   │
│    GET /              → 大盘总览页                        │
│    GET /detail/{code} → 指数详情（ECharts 时序图）         │
│    GET /api/indices   → 所有指数最新指标 (JSON)           │
│    GET /api/indices/{code}?start=&end= → 时序数据 (JSON) │
│    GET /api/compare?codes=  → 多指数对比 (JSON)           │
└─────────────────────────────────────────────────────────┘
```

## 五、前端页面说明

### 5.1 大盘总览页（`/`）

访问 `http://<IP>:8000` 打开。

**页面结构：**
- 顶部：标题 + 数据更新日期
- 主体：按类别分组（宽基 / 红利 / 港股通 / 港股 / 美股 / 质量），每类一个网格

**每张卡片显示：**

| 字段 | 含义 |
|------|------|
| PE | 当前市盈率（优先显示中证整体法 PE，无则用蛋卷等权 PE） |
| PB | 当前市净率（蛋卷数据，部分指数未覆盖显示"—"） |
| PE百分位 | 当前 PE 在历史中的位置，绿(<30%) / 黄(30-70%) / 红(>70%) |
| FED | 股债性价比，(1/PE)*100 - 10Y国债收益率，正值=股票偏宜 |
| 更新 | 数据的最新日期 |

**交互：** 点击任意卡片进入该指数的详情页。

### 5.2 指数详情页（`/detail/{code}`）

点击大盘卡片进入，或直接访问 `http://<IP>:8000/detail/000300`。

**顶部指标卡：**
显示 PE、PB、PE百分位、FED 的最新值和颜色状态。

**图表区域（4张图）：**

| 图表 | 类型 | 内容 |
|------|------|------|
| PE TTM 走势 | 折线 + 面积 | PE 历史走势，P30（绿线）/P70（红线）参考线 |
| PE 百分位历史走势 | 折线（绿-黄-红变色） | PE 百分位从历史最低到最高的变化过程，30%/70% 虚线分界 |
| FED 股债性价比 | 柱状（绿/红） | 绿色=股票偏宜，红色=股票偏贵 |
| PB 走势 | 折线 | 有 PB 数据的指数显示，无则提示"不覆盖" |

**返回：** 点击左上角"← 大盘总览"回到首页。

### 5.3 前端架构说明

- **后端**：FastAPI，无需重启即可读取最新 parquet
- **前端**：纯 HTML + ECharts CDN（`cdn.jsdelivr.net`），无构建步骤
- **图表**：ECharts 5.5，CDN 加载，首次打开需联网
- **数据流**：页面 JS `fetch /api/indices` → FastAPI `pd.read_parquet` → JSON → ECharts 渲染
- **刷新**：手动 F5，无自动轮询

### 6.2 merged parquet 列结构

| 列名 | 来源 | 说明 |
|------|------|------|
| `date` | 统一 | 日期索引 |
| `pe_ttm_dj` | Danjuan | 等权 PE TTM |

| `fed_dj` | 计算 | (1/pe_ttm_dj)*100 - bond_yield |

## 九、常见问题

### 服务相关

| 问题 | 原因 | 解决 |
|------|------|------|
| 网页打不开 | 服务进程已退出 | `ps aux \| grep app.py` 查看进程；`setsid python3 -u app.py &>/tmp/pedca.log & disown` 重启 |
| 端口冲突 | 8000 已被占用 | `kill $(ss -tlnp \| grep 8000 \| grep -oP 'pid=\K\d+')` 杀掉后再启动 |
| 外网 8000 不通 | 防火墙 | `sudo firewall-cmd --add-port=8000/tcp` 或 `iptables -A INPUT -p tcp --dport 8000 -j ACCEPT` |
| 日志查看 | — | `cat /tmp/pedca.log` |

### 数据相关

| 问题 | 原因 | 解决 |
|------|------|------|
| CSI 下载返回 403 | WAF 限频 | 已内置 3s 间隔，等几分钟再试 |
| 399006/399330 无数据 | 深交所指数，CSI API 不覆盖 | 正常，蛋卷已覆盖这两个 |
| 部分指数无 PB | 蛋卷不覆盖 930xxx 系列 | 正常，见覆盖矩阵 |
| PB 显示"—" | merge 未跑或未 forward-fill | 重跑 `merge_indicators.py` |
| 数据不更新 | 只跑了采集忘了合并 | 必须跑 `merge_indicators.py` 才生效 |
| 更新后页面不刷新 | 浏览器缓存 | F5 硬刷新（Ctrl+F5） |

### 前端相关

| 问题 | 原因 | 解决 |
|------|------|------|
| 图表不显示 | ECharts CDN 加载失败 | 检查外网连接，CDN 地址 `cdn.jsdelivr.net` |
| 详情页空白 | 指数代码不存在 | 检查 URL 中的代码是否正确（如 `000300` 不是 `300`） |
| 卡片数据为"—" | 该指标在该指数上确无数据 | 见覆盖矩阵 |

### 10.2 存储结构

```
data-store/parquet/
├── wind_source/          ← Wind 原始数据（不混入现有，独立存放）
│   ├── 000015.parquet    (上证红利，5168条，2005起)
│   ├── 000016.parquet    (上证50，5411条，2004起)
│   ├── 000300.parquet    (沪深300，5107条，2005起)
│   ├── ...
│   └── SPX500.parquet    (标普500，8531条，1990起)
├── aligned_source/       ← 对齐后的最终数据（Wind 早期 + 现有近期）
│   └── {code}.parquet
│       col: date, pe_aligned, pe_source(wind/ours),
│            pe_ttm_wind, pe_ttm_ours, pe_pct_aligned
├── index_pe/             ← 原有（不动）
├── index_pb/             ← 原有（不动）
└── merged/               ← 原有（不动）
```

### 10.3 对齐策略

```
Wind 数据:  ████████████████████████╮  1990~2026-04-16
                                    ├─ 对齐点: 2026-04-16
现有数据:                            ╰████████████  2026-04-17~2026-08-04
                                    
对齐结果:  ████████████████████████████████████  一条连续线
           Wind 补早期     现有补近期
```

- **对齐点**：2026-04-16（Wind 数据截止日）
- 对齐点之前：使用 Wind PE 值
- 对齐点之后：使用现有系统 PE 值（蛋卷/中证）
- 对齐后的百分位基于合并后的全量历史重新计算

### 10.4 导入命令

```bash
python data-store/import_wind_data.py     # xlsx → parquet/wind_source/
python data-store/align_wind_data.py      # 合并 → parquet/aligned_source/
```
