## 五、接口返回示例

以沪深300（SH000300）为例，请求：
```
GET https://danjuanfunds.com/djapi/index_eva/pe_history/SH000300?day=all
```

返回 JSON：
```json
{
  "result_code": 0,
  "data": {
    "index_eva_pe_growths": [
      {"pe": 12.3699, "ts": 1470240000000},
      {"pe": 12.5548, "ts": 1470672000000},
      ...
      {"pe": 14.2115, "ts": 1785772800000}
    ]
  }
}
```

字段说明：
- `pe`：PE TTM 值（等权口径）
- `ts`：毫秒时间戳，需 `pd.to_datetime(ts, unit='ms')` 转换

## 六、核心下载代码

```python
import requests
import pandas as pd

def fetch_danjuan_pe(danjuan_code: str) -> pd.DataFrame:
    """
    从蛋卷基金获取PE TTM历史数据（周频）。

    Args:
        danjuan_code: 蛋卷格式代码，如 "SH000300"

    Returns:
        DataFrame: date, pe_ttm_dj  （空DataFrame表示无数据）
    """
    url = f"https://danjuanfunds.com/djapi/index_eva/pe_history/{danjuan_code}"

    r = requests.get(
        url,
        params={"day": "all"},
        headers={"User-Agent": "Mozilla/5.0"},
        timeout=15,
    )
    data = r.json()

    if "data" not in data or not data["data"]:
        return pd.DataFrame()

    pe_items = data["data"].get("index_eva_pe_growths", [])
    if not pe_items:
        return pd.DataFrame()

    df = pd.DataFrame(pe_items)
    df["date"] = pd.to_datetime(df["ts"], unit="ms").dt.date
    df["pe_ttm_dj"] = pd.to_numeric(df["pe"], errors="coerce")
    return df[["date", "pe_ttm_dj"]].sort_values("date").reset_index(drop=True)
```

## 八、注意事项

1. **周频数据**：蛋卷PE是周频（每周1个采样点），不是日频。现有 `download_index_pe.py` 通过 `merge_asof` 前向填充到日频K线使用。

2. **数据起始统一为 2016-08-03**：大部分指数从 2016-08-03 起有数据，科创50从 2019-12-30（指数发布日），恒生科技从 2020-07-26（指数发布日）。

3. **2个指数无数据**：港股综合(930930)、港股通50(930931) 在蛋卷无PE数据，使用中证指数公司官方PE（整体法加权PE）兜底。

4. **蛋卷代码需加前缀**：A股加 `SH`/`SZ`，港股加 `HK`，美股用蛋卷专用简称。

5. **无需认证**：接口无需Token，直接GET请求即可，但建议加 `User-Agent` 头避免被拒。

6. **与理杏仁对比**：蛋卷PE为周频且仅2016年起；理杏仁PE为日频且从指数发布日起有数据，但中证1000和恒生科技相关系数极低（详见 `data-store/lixinger/理杏仁PE数据对比验证报告_2026-04-15.md`）。
